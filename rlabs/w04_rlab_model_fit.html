Assumptions

MVPA models estimated with maximum likelihood carry a handful of assumptions.

Multivariate normality

ML assumes the endogenous variables are multivariate normal.

mardia(pisa)
Call: mardia(x = pisa)

Mardia tests of multivariate skew and kurtosis
Use describe(x) the to get univariate tests
n.obs = 3763   num.vars =  4 
b1p =  3.04   skew =  1904.95  with probability  <=  0
 small sample skew =  1907.08  with probability <=  0
b2p =  28.04   kurtosis =  17.88  with probability <=  0

Interpretation: Significant results indicate evidence against multivariate normality, so we fit with a robust estimator, estimator = "MLR", which corrects the standard errors and the chi-square for non-normality.

Linearity

The ~ paths assume each relationship is linear. Scatterplots with a straight (lm) fit overlaid let us eyeball the two paths into reading.

pisa |>
  select(BOOKSHOME, TECH, READ_AVG) |>
  pivot_longer(-READ_AVG, names_to = "predictor", values_to = "x") |>
  ggplot(aes(x, READ_AVG)) +
  geom_point(alpha = 0.15) +
  geom_smooth(method = "lm", se = FALSE, colour = "#C81E7A") +
  facet_wrap(~predictor, scales = "free_x") +
  theme_minimal()

Multicollinearity

The two predictors that appear together in the reading equation are books at home and technology. They should not be near-perfectly correlated.

vars <- c("PAREDINT", "BOOKSHOME", "TECH", "READ_AVG")
cor(pisa[, vars], use = "pairwise.complete.obs")

BOOKSHOME 0.2721712 1.0000000 0.2992901 0.4238771
TECH      0.2057440 0.2992901 1.0000000 0.1309244

# Variance inflation factor for the BOOKSHOME / TECH pair
r2  <- summary(lm(BOOKSHOME ~ TECH, data = pisa))$r.squared
vif <- 1 / (1 - r2)
vif
[1] 1.098388

Uncorrelated disturbances

Recursive path models assume the disturbances of the endogenous variables are uncorrelated. We enforce this when fitting with auto.cov.y = FALSE.

After fitting we check the residual covariances.

MVPA Models

One research decision note:

We have two ordinal variables, but each has more than 5 levels, so we follow convention that 5 or more levels may be treated as continuous.

Model 0: Original Example

This is the model we’ve been looking at in class.

Does parent education relate to reading achievement through books at home?

This question does not imply any model comparison.

\[\text{PAREDINT} \;\rightarrow\; \text{BOOKSHOME} \;\rightarrow\; \text{READ\_AVG}\]

model0 <- "
  BOOKSHOME ~ PAREDINT
  READ_AVG  ~ BOOKSHOME
"

fit0 <- lavaan(model0, data = pisa, auto.var = TRUE, auto.cov.y = FALSE, estimator = "MLR")

Is Model 2 better than Model 1?

Because Model 1 is nested in Model 2 (Model 1 = Model 2 with the TECH -> READ_AVG path fixed to 0), we can compare them with a chi-square difference test, and also weigh parsimony with AIC/BIC.

anova(fit1, fit2)
