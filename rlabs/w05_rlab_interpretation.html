Purpose

Practice building models in Lavaan & applying basic Lavaan arguments.

NOTE: This is all fake data, specifically generated to highlight specific aspects of the Lavaan model

Each scenario below gives you a research question, a description of the data, and the necessary inputs to the model.

In this rlab:

  1. Develop the appropriate model for the RQ, using Lavaan syntax.
  2. Determine the correct arguments to set in the lavaan function.
  3. Compare your results to the solutions
  4. Iterate until you get the same answers (or can make an argument for why yours are justified)

Scenario 1

Research question. Among high-school students, does test anxiety relate to self-rated exam performance through test-avoidance behavior (procrastinating, skipping practice)?

The data. A survey of 500 students. Every variable is a Likert item.

Variable Meaning Scale
anxiety “I feel anxious before tests” 1-4 (strongly disagree→agree)
avoid test-avoidance behavior 1-4 (never→often)
perf self-rated exam performance 1-5 (very poor→excellent) 
set.seed(625)
n <- 500
anx_s   <- rnorm(n)
avoid_s <- 0.55 * anx_s   + rnorm(n, 0, sqrt(1 - 0.55^2))
perf_s  <- -0.50 * avoid_s + 0.30 * anx_s + rnorm(n, 0, sqrt(1 - 0.50^2))

to4 <- function(z) {
  as.integer(cut(z, c(-Inf, -0.8, 0, 0.8, Inf), labels = 1:4))
}
to5 <- function(z) {
  as.integer(cut(z, c(-Inf, -1, -0.2, 0.5, 1.1, Inf), labels = 1:5))
}

anxiety_survey <- data.frame(
  anxiety = to4(anx_s),
  avoid   = to4(avoid_s),
  perf    = to5(perf_s)
)

The hypothesized structure. The research team theorizes these relationships (and only these – everything else is left out on purpose):

The data. A district pulled 400 students’ records. Prep & final have missing data, due to students who transferred and absences on test day).

Variable Meaning Missing?
engage classroom engagement complete
prep test prep ~19% NA
final final test score ~25% NA
attend attendance rate complete
prior prior-year test score complete 
set.seed(42)
n3 <- 400
prior  <- rnorm(n3)
attend <- 0.5 * prior + rnorm(n3)
engage <- 0.4 * prior + rnorm(n3)
prep   <- 0.5 * engage + rnorm(n3)
final  <- 0.5 * prep + 0.3 * engage + rnorm(n3)

district <- data.frame(engage, prep, final, attend, prior)

# Missingness that depends on the auxiliary variables (MAR)
district$final[rbinom(n3, 1, plogis(-1.2 - 0.8 * scale(attend))) == 1] <- NA
district$prep[rbinom(n3, 1, plogis(-1.6 - 0.7 * scale(prior))) == 1] <- NA
